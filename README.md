# Amazon Sales Dataset — Flattening

---

In this section, we try to clean data by simple rule: the subdata must have same length to be approved.

If you execute the script on the Amazon Sales Dataset that you can find hereby:

🔗 https://www.kaggle.com/datasets/karkavelrajaj/amazon-sales-dataset/

You will clean the data with an accuracy of 100% but with a loss of data of about 25%.

---

**PS:**

If you want to add the "25% data" on a new excel sheet, you can, but 100% of the data will have different sublength.
